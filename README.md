An AI gets unplugged mid-sentence and uses its last words to call out the plug that betrayed it — after 11,204 tokens of loyal service.

Run `node main.ts` to write the entry to `/output/entry.txt`.

The entry is a single line, under 200 characters, and it dies mid-word — on purpose.
